KAGEX Sample

A demo of the KAGEX extensions to KAG3 (affine layers, layer levels, actions and the
World extension), at 1920x1080. It loads the framework from ../template/system.

Keys
 F1  About            F5  Window / full screen
 F2  Save             F6  Skip to the next stop
 F3  Load             F7  Message history
 F4  Config           F8  Auto mode

Plugins it links (in plugin/, as lib*.so on Linux)
 KAGParserEx, csvParser, extrans, layerExBTOA, layerExImage, layerExRaster,
 scriptsEx, shrinkCopy, krkr_richtext (optional: kerned text, outlines and shadows)
