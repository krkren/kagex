Title: KAGEX Initial Setup
Original: Go Watanabe, 2012/4/29 (updated for the SDL3 port)

1. Getting it

  Download a package from https://github.com/krkren/kagex/releases, unzip it and run
  krkrz.exe (Windows) or ./krkrz (Linux). README.md lists what each platform needs.
  The packages include the engine, built from https://github.com/wamsoft/krkrz_dev;
  this repository holds only the scripts and assets.

2. About the sample data

  template/   The KAGEX framework (template/system) and empty folders for a new game.
  data/       The sample game, with its system scripts (title screen, etc.).

  Files under data/ load template/system.

  When releasing a game, copy template/system and template/startup.tjs into the data
  directory. template/main/ has empty versions of the game-side hooks to start from.
