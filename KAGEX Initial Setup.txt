Title: KAGEX Initial Setup
Original: Go Watanabe, 2012/4/29 (updated for the SDL3 port)

1. Getting it

  Download a package from https://github.com/krkren/kagex/releases, unzip it and run
  krkrz.exe (Windows) or ./krkrz (Linux). README.md lists what each platform needs.
  The packages include the engine, built from https://github.com/wamsoft/krkrz_dev;
  this repository holds only the scripts and assets.

2. About the sample data

  template/   The KAGEX framework (template/system) and empty folders for a new game.
  data/       The sample game, with its system scripts (title screen, etc.).

  Files under data/ load template/system.

  When releasing a game by hand, copy template/system and template/startup.tjs into the
  data directory. template/main/ has empty versions of the game-side hooks to start from.

3. Releasing a game

  tools/kagex-release (tools/kagex-release.exe on Windows) packages the game next to it
  for Windows, Linux, Linux for Steam, macOS, the web, Android and iOS. It opens a window
  with the settings, which it saves to release.json next to data/, and can convert the
  game's WAV, FLAC, PNG and BMP files to Opus and TLG6 on the way. tools/release/README.md
  in the repository describes every option, and `kagex-release --cli build` runs it without
  the window.

4. Live2D characters

  The packages can't carry Live2D's Cubism Core (its licence lets it go out inside a game
  only), so the plugin that draws Live2D characters is built with your own copy of Live2D's
  Cubism SDK for Native. tools/live2d/setup.py, in the repository, walks you through it: put
  the repository's tools/live2d folder (from https://github.com/krkren/kagex, at this release's
  tag) next to data/ as tools/live2d, with tools/assets/make_hiyori.py (it fetches the
  sample's Hiyori) and tools/smoketest.py (its quick check) beside it as in the repository,
  and run python3 tools/live2d/setup.py. To play the sample
  with Live2D first, download kagex_sample_live2d_<platform> from the release, where there is
  one. doc/world.txt, "Live2D Characters", describes them.
