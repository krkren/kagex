同じ絵を二つ：左は PNG、右は SVG のベクター画像です。
拡大すると PNG はぼやけますが、SVG は大きさごとに描き直されるのでくっきりしたまま
です。
どちらもほかのレイヤと同じように回転します。
CLIP STUDIO PAINT のファイルひとつから、レイヤを二枚それぞれ clip:// で読み込んでい
ます。
なので、パーツごとに別々に動かせます。
このビルドでは Live2D モデルを再生できません。Live2D の Cubism SDK でビルドした 
krkrlive2d プラグインとモデルが必要です。追加のしかたは doc/world.txt の「Live2D 
Characters」にあります。
レイヤには 3D のシーンも表示できます。これはスクリプトで組み立てたシーンで、形とマ
テリアルとライトがあり、カメラがまわりを回ります。
3donce は何かを一度だけ再生します。このシーンのスクリプトでは結び目が跳びます。
glTF のモデルは自分のアニメーションを再生します。spin がずっと続き、3donce=hop で
跳びます。
VRM のアバターは立って、まばたきして、VRM アニメーションを再生します。3dmotion は
ずっと続き、3donce=vee_wave で一度手を振ります。
3dturn はモデルを回します。絵はふつうのレイヤと同じように、動かしたり、拡大したり、
回したりできます。

extNagano プラグインでトランジションがさらに増えます。そのうち7種類をご覧ください。
blurfade：ぼかしを通したクロスフェード
flutter：絵が紙のようにはがれていく
scanline：線が左右交互にすべり込む
3duniversal：ルール画像で破片が飛び散る（ここではガラス片）
imagewipe：画像に沿ったワイプ（ここでは筆のストローク）
morphing：三角形で絵をゆがめる（ここでは渦巻き、envinit.tjs）
honeyturn：六角形がひとつずつ裏返る
kagex 独自のグリッチ・トランジションは、絵を乱しながら次の絵へ移ります。
glitch：データモッシュ、壊れたストリーム、崩れたブロックが次々に
style=mosh：古い絵が新しい絵の動きに沿って溶けていく
style=digital：欠けたブロック、壊れた JPEG、並べ替えられた画素
style=analog：流れ、傾き、色のずれる乱れた信号
そして [glitch]：同じ画面が一瞬だけ乱れます。ここでは控えめに、毎回同じものを。
選択肢：Effekseer エフェクト
光る花びらが道に舞います。World レイヤに置いた Effekseer エフェクトを krkreffekseer 
プラグインが描いています。
[あい] 花びら……光ってる？
[あい] キラキラも、まわりじゅうに！
エフェクトはそれぞれ独立したレイヤです。efk= で指定し、efkmag で大きさを決め、
efkwidth と efkheight でキャンバスの大きさを決めます。配置はふつうのレイヤと同じで
す。
[あい] 花火だ！
レイヤが再生されているあいだ、だいたい一秒に一発ずつ打ち上がります。
[あい] ん？ あっちで何か光ってる……
[あい] わっ！
今のような爆発は一度だけ再生され、終わるとレイヤも消えます。
efkstop を指定すると、エフェクトはパーティクルを出すのをやめてフェードアウトします。
[あい] 今度は、わざと調子の悪くなるエフェクトだよ。
画面が砂嵐に乱れます。level=message の World レイヤに置いた static フリップを、レイ
ヤの不透明度で場面とこのウィンドウに重ねて描いています。
[あい] 音楽も……テープが伸びたみたいに、ゆっくりになってく！
pitch= は音の速さと高さをいっしょに変えます。ここでは二秒半かけて音楽を 35% まで落
としています。
[あい] 今、誰か通った？
pan= は音を左右に動かします。ここでは足音が片側からもう片側へ横切ります。
[あい] ふう、元どおり。
[あい] 見てくれてありがとう！
選択肢：ワールド拡張：アニメキャラクタ
ピップは表示するときにレイヤを組み合わせて描かれます。体がひとつ、衣装がふたつ、腕
のポーズが三つ、表情が六つです。
[ピップ] やあ！ ぼくはピップ。
[ピップ] ひとりでまばたきするし、声にあわせて口も動くよ。
目は数秒ごとにまばたきし、しゃべっているあいだは声の大きさに応じて口が開きます。
[ピップ] もう一回こんにちは！ よく聞いてね。本物の声でしゃべると、ぼくの口は言った
母音ひとつひとつの形になるんだ。あー、いー、うー、えー、おー。もごもご言うより、ずっ
といいでしょ？
このせりふでは、kagex-lipsync が声とその文からそれぞれの母音を言うタイミングを割り
出し、声の隣に pip000009.lip を書きました。ほかの声はどれも、声の大きさだけで口を動
かします。
[ピップ] おっ！ 新しい顔だ！
xsurprised のように表情の前に x をつけると、表情が変わるあいだ目を閉じます。
[ピップ] おっと、びっくりさせちゃった？
[ピップ] どうかな、似合う？
[ピップ] あはは！ 気に入った！
笑い顔は目を閉じた絵なのでまばたきはしませんが、口は動きます。
[ピップ] ちょっと！ あの帽子、気に入ってたのに！
衣装も表情と同じように変わります。beret で帽子をかぶり、plain で脱ぎます。
World のレベルごとにその大きさで描いたレイヤがあるので、近づいてもピップはくっきり
したままです。
目と口は命令でも動かせます。eyecloseto は目を閉じ、閉じ終わるまで待ちます。
そして eyeopento でまた開きます。
eyeflip=3 で三回まばたきします。
lipflip=4 なら、声なしで口を四回動かします。
[ピップ] またね！
あの手を振る動きはアニメーションです。data/main/charanim.csv の waving が、ほかの
変化があるまでタイマーで腕のポーズを切り替えています。
ひとつのレイヤーファイルから作った CG です。空、丘、ピップ、その腕や表情がそれぞれ
レイヤーで、この絵はその一部を見せています。
pipcg_laugh は同じファイルの別のレイヤーを見せたもの。ばんざいの腕と笑顔です。
pipcg_evening は夕方の空と、全体にかかるオレンジ色の光、それにベレー帽。
pipcg_night は月と星と眠そうな顔。ファイルはひとつ、絵は四枚で、ギャラリーではそれ
ぞれの名前で並びます。
このビルドでは Live2D モデルを再生できません。Live2D の Cubism SDK でビルドした 
krkrlive2d プラグインとモデルが必要です。追加のしかたは doc/world.txt の「Live2D 
Characters」にあります。
こちらはヴィー、VRM のアバターです。VRoid Studio が書き出すのと同じ形式の 3D モデ
ルで、このサンプルのためにスクリプトが簡単な形から組み立て、krkrthreepp プラグイン
が描いています。
[ヴィー] こんにちは！ヴィーです。3D モデルだから、向きを変えたり、手を振ったり、跳
びはねたりできます。話すときは、母音ごとに口の形も変わるんですよ！
口は、声から kagex-lipsync が作ったリップトラックに従います。母音ごとに、アバター自
身の aa、ih、ou、ee、oh の表情が使われます。
顔はアバターの表情の重みの組み合わせです。laugh は happy をいっぱいに、smile はそれ
より少なめにしたものです。
happy、sad、angry、relaxed、surprised のようなよく使う表情は VRM が名前を決めてい
るので、同じ顔がそれを持つどのアバターにも使えます。
アバターは自分だけの表情も持てます。blush はヴィーのものです。
wave は VRM アニメーションを一度だけ再生し、motionwait はその終わりを待ちます。そ
のあとはポーズのアニメーションに戻ります。
ポーズはループする VRM アニメーションです。think は、次のポーズが来るまで手をあごに
当てたままにします。
アニメーションは次のアニメーションへフェードするので、nod はポーズのとちゅうの姿勢
からそのまま始まります。
動くとツインテールが揺れます。VRM のスプリングボーンです。
