同じ絵を二つ：左は PNG、右は SVG のベクター画像です。
拡大すると PNG はぼやけますが、SVG は大きさごとに描き直されるのでくっきりしたままで
す。
どちらもほかのレイヤと同じように回転します。
CLIP STUDIO PAINT のファイルひとつから、レイヤを二枚それぞれ clip:// で読み込んでいます。
なので、パーツごとに別々に動かせます。
このビルドでは Live2D モデルを再生できません。Live2D の Cubism SDK でビルドした 
krkrlive2d プラグインとモデルが必要です。追加のしかたは doc/world.txt の「Live2D 
Characters」にあります。
レイヤには 3D のシーンも表示できます。これはスクリプトで組み立てたシーンで、形とマテ
リアルとライトがあり、カメラがまわりを回ります。
3donce は何かを一度だけ再生します。このシーンのスクリプトでは結び目が跳びます。
glTF のモデルは自分のアニメーションを再生します。spin がずっと続き、3donce=hop で跳び
ます。
VRM のアバターは立って、まばたきして、VRM アニメーションを再生します。3dmotion はずっ
と続き、3donce=vee_wave で一度手を振ります。
3dturn はモデルを回します。絵はふつうのレイヤと同じように、動かしたり、拡大したり、回
したりできます。

extNagano プラグインでトランジションがさらに12種類増えます。
book：ページがめくれる
flutter：絵が紙のようにはがれていく
blurfade：ぼかしを通したクロスフェード
zoomfade：消えながら拡大する
scanline：線が左右交互にすべり込む
rgbfade：赤・緑・青が順番に切り替わる
spin：箱の側面のように絵が回る
multiripple：五か所から波紋が広がる
imagewipe：画像に沿ったワイプ（ここでは筆のストローク）
3duniversal：ルール画像で破片が飛び散る（ここではガラス片）
honeyturn：六角形がひとつずつ裏返る
morphing：三角形で絵をゆがめる（ここでは渦巻き、envinit.tjs）
選択肢：Effekseer エフェクト
光る花びらが道に舞います。World レイヤに置いた Effekseer エフェクトを krkreffekseer プラ
グインが描いています。
[あい] 花びら……光ってる？
[あい] キラキラも、まわりじゅうに！
エフェクトはそれぞれ独立したレイヤです。efk= で指定し、efkmag で大きさを決め、
efkwidth と efkheight でキャンバスの大きさを決めます。配置はふつうのレイヤと同じです。
[あい] 花火だ！
レイヤが再生されているあいだ、だいたい一秒に一発ずつ打ち上がります。
[あい] ん？ あっちで何か光ってる……
[あい] わっ！
今のような爆発は一度だけ再生され、終わるとレイヤも消えます。
efkstop を指定すると、エフェクトはパーティクルを出すのをやめてフェードアウトします。
[あい] 今度は、わざと調子の悪くなるエフェクトだよ。
画面が砂嵐に乱れます。level=message の World レイヤに置いた static フリップを、レイヤの
不透明度で場面とこのウィンドウに重ねて描いています。
[あい] 音楽も……テープが伸びたみたいに、ゆっくりになってく！
pitch= は音の速さと高さをいっしょに変えます。ここでは二秒半かけて音楽を 35% まで落と
しています。
[あい] 今、誰か通った？
pan= は音を左右に動かします。ここでは足音が片側からもう片側へ横切ります。
[あい] ふう、元どおり。
[あい] 見てくれてありがとう！
選択肢：ワールド拡張：アニメキャラクタ
ピップは表示するときにレイヤを組み合わせて描かれます。体がひとつ、衣装がふたつ、腕の
ポーズが三つ、表情が六つです。
[ピップ] やあ！ ぼくはピップ。
[ピップ] ひとりでまばたきするし、声にあわせて口も動くよ。
目は数秒ごとにまばたきし、しゃべっているあいだは声の大きさに応じて口が開きます。
[ピップ] もう一回こんにちは！ よく聞いてね。本物の声でしゃべると、ぼくの口は言った母音
ひとつひとつの形になるんだ。あー、いー、うー、えー、おー。もごもご言うより、ずっとい
いでしょ？
このせりふでは、kagex-lipsync が声とその文からそれぞれの母音を言うタイミングを割り出
し、声の隣に pip000009.lip を書きました。ほかの声はどれも、声の大きさだけで口を動かし
ます。
[ピップ] おっ！ 新しい顔だ！
xsurprised のように表情の前に x をつけると、表情が変わるあいだ目を閉じます。
[ピップ] おっと、びっくりさせちゃった？
[ピップ] どうかな、似合う？
[ピップ] あはは！ 気に入った！
笑い顔は目を閉じた絵なのでまばたきはしませんが、口は動きます。
[ピップ] ちょっと！ あの帽子、気に入ってたのに！
衣装も表情と同じように変わります。beret で帽子をかぶり、plain で脱ぎます。
World のレベルごとにその大きさで描いたレイヤがあるので、近づいてもピップはくっきりし
たままです。
目と口は命令でも動かせます。eyecloseto は目を閉じ、閉じ終わるまで待ちます。
そして eyeopento でまた開きます。
eyeflip=3 で三回まばたきします。
lipflip=4 なら、声なしで口を四回動かします。
[ピップ] またね！
あの手を振る動きはアニメーションです。data/main/charanim.csv の waving が、ほかの変化
があるまでタイマーで腕のポーズを切り替えています。
このビルドでは Live2D モデルを再生できません。Live2D の Cubism SDK でビルドした 
krkrlive2d プラグインとモデルが必要です。追加のしかたは doc/world.txt の「Live2D 
Characters」にあります。
こちらはヴィー、VRM のアバターです。VRoid Studio が書き出すのと同じ形式の 3D モデルで、
このサンプルのためにスクリプトが簡単な形から組み立て、krkrthreepp プラグインが描いて
います。
[ヴィー] こんにちは！ヴィーです。3D モデルだから、向きを変えたり、手を振ったり、跳びは
ねたりできます。話すときは、母音ごとに口の形も変わるんですよ！
口は、声から kagex-lipsync が作ったリップトラックに従います。母音ごとに、アバター自身
の aa、ih、ou、ee、oh の表情が使われます。
顔はアバターの表情の重みの組み合わせです。laugh は happy をいっぱいに、smile はそれよ
り少なめにしたものです。
happy、sad、angry、relaxed、surprised のようなよく使う表情は VRM が名前を決めている
ので、同じ顔がそれを持つどのアバターにも使えます。
アバターは自分だけの表情も持てます。blush はヴィーのものです。
wave は VRM アニメーションを一度だけ再生し、motionwait はその終わりを待ちます。その
あとはポーズのアニメーションに戻ります。
ポーズはループする VRM アニメーションです。think は、次のポーズが来るまで手をあごに当
てたままにします。
アニメーションは次のアニメーションへフェードするので、nod はポーズのとちゅうの姿勢か
らそのまま始まります。
動くとツインテールが揺れます。VRM のスプリングボーンです。
