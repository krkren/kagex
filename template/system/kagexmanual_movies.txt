# Movies Don't Play
- If a movie shows its first picture and then ends after a few seconds, the game found no sound output: connect speakers or headphones (or turn the sound device on) and start the game again.
- If a movie stutters, [play the smaller one](option:movieQuality=small).
- Subtitles: [on](option:subtitles=true) [off](option:subtitles=false).
- Movie volume: [quiet](option:movieVolume=40) [loud](option:movieVolume=80).

A click skips a movie you've already seen.
